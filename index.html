Konfigurasi Sinkronisasi Cloud (Firebase)

Untuk menyinkronkan file PDF dan akun anggota secara real-time antar komputer & HP di GitHub Pages, tempelkan objek konfigurasi Firebase Web App Anda di bawah ini (atau isi langsung di dalam kode HTML).

Panduan Hosting GitHub Pages & Kolaborasi Tim

1. Cara Upload ke GitHub Pages (Gratis & Cepat)

  1. Buat repositori baru di GitHub (misalnya: arsip-walhi-malut).
  2. Unggah file ini dengan nama index.html ke branch main.
  3. Buka menu Settings → Pages, pilih Source Deploy from a branch (main / /root), lalu klik Save.
  4. Dalam 1–2 menit, aplikasi web resmi WALHI MALUT dapat diakses secara online.

2. Sinkronisasi Real-Time Antar Anggota (Firebase)

Agar setiap file PDF yang diposting oleh satu staf langsung muncul di layar staf lain yang berada di lokasi berbeda:

  1. Buat proyek gratis di Firebase Console, aktifkan Authentication (Anonymous), Firestore Database, dan Storage.
  2. Klik tombol Pengaturan (ikon gerigi) di sidebar aplikasi ini dan masukkan konfigurasi Firebase Anda.
  3. Jika belum dikonfigurasi, aplikasi tetap berjalan normal menggunakan penyimpanan lokal browser (IndexedDB) dan mendukung fitur Backup/Restore JSON.
